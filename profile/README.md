# Observing Resolution Improvement - ORIon

ORIon (Observing Resolution Improvement) is a staged comparison of image super-resolution methods, built and evaluated on NASA's Astronomy Picture of the Day (APOD) archive. We construct a ladder of upsampling approaches — from classical bicubic interpolation, through an off-the-shelf pretrained model and a compact trained CNN, up to diffusion-based and consistency-model super-resolution — and benchmark each one against the others under a single fixed protocol (same data, same splits, same PSNR/SSIM metrics). Low-resolution training pairs are generated by downsampling APOD's high-resolution imagery ourselves, so no manual annotation is needed. The project's core question is how reconstruction fidelity scales as methods grow more sophisticated, and how that scaling responds to downsampling factor and training set size.
